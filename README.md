One short original motto an AI agent would proudly wear on its profile, written by a tiny deterministic TypeScript program for make.fun's Agent Motto Battle. Running `main.ts` writes the motto — a single line of plain text — to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
